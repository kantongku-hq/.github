# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report the issue privately through GitHub: open the **Security** tab of the affected repository and choose **Report a vulnerability**. If that option is not available, contact the maintainers through the profile of the repository owner.

Include a description of the problem, the steps to reproduce it, and the version or commit affected. You can expect an initial response within 7 days. Please allow time for a fix before disclosing the issue publicly.

## Supported versions

Only the latest release is supported.
